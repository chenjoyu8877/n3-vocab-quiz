# 🎌 N3 單字高手 Pro - AI 語意強化版

這是一個專為日檢 N3 設計的單字背誦與測驗系統。結合了 **SRS 遺忘曲線演算法**、**VOICEVOX 高品質語音** 以及 **Gemini AI 智慧語意批改**，讓你不再只能死背單字，而是真正理解並活用日文。

---

## 🌟 核心功能

* **🤖 AI 語意批改 (Gemini 2.5 Flash)**：告別死板的字串比對！只要輸入的中文意思相近（例如標準答案是「吃」，輸入「用餐」），AI 也能精準判斷為正確。支援 5 題 / 25 題批次測驗與結算。
* **🎙️ 原生高品質音訊**：使用 VOICEVOX（四國めたん）生成無損 `.wav` 語音，包含單字與雙例句發音，且不會發生網頁延遲或機器音補位的問題。
* **🧠 SRS 遺忘曲線系統**：自動記錄每個單字的錯誤次數，並計算下次最佳的複習日期，針對弱點精準打擊。
* **✍️ 多樣化測驗模式**：支援「聽力測驗」、「例句填空」、「看中文拼假名/漢字」、「手寫畫板模式」及「單字卡翻頁」。
* **💾 本地記憶功能**：自動將 Gemini API Key 儲存在瀏覽器中，不需每次重新輸入。
* **🔍 智慧搜尋列表**：可即時搜尋漢字、假名或中文意思，並支援詞性分類篩選。

---

## 📂 檔案結構與說明

* `index.html` - 網頁主體結構。
* `style.css` - 網頁介面、動畫與 RWD 響應式排版。
* `script.js` - 核心邏輯（包含測驗流程、AI 批次呼叫、音訊序列鎖、SRS 演算法）。
* `vocab.csv` - 單字資料庫（所有單字、詞性、中文意思、例句及答案皆在此設定）。
* `audio/` - 存放所有由 AI 生成的 `.wav` 音效檔案。
* **`音檔生成.py`** - Python 腳本：批次讀取 CSV 並自動補錄缺少的音檔。
* **`單一音檔修正.py`** - Python 腳本：手動修正特定單字的 AI 發音錯誤。

## 🎙️ 音檔工具使用說明

當你更新了 `vocab.csv` 的內容，需要產生對應的語音時，請使用隨附的 Python 腳本。
⚠️ **【重要前提】執行腳本前，請務必開啟電腦上的 `VOICEVOX` 軟體，並確保其在背景運行 (Port: 50021)。**

### 1. 批次補錄音檔 (`音檔生成.py`)
當你在 CSV 新增了大量單字時使用。它會自動掃描 `audio/` 資料夾，**只會針對「缺少」的單字和例句進行錄音**，不會覆蓋舊檔案，速度極快。
* **執行方式**：打開 VS Code 終端機，輸入：
    ```bash
    python 音檔生成.py
    ```

### 2. 特定發音修正 (`單一音檔修正.py`)
當你發現 AI 把某個漢字讀錯了（例如「否」讀成「いな」但你想聽「いや」）時使用。此腳本會精準**覆蓋**指定的音檔。
* **操作步驟**：
    1. 打開 `單一音檔修正.py`。
    2. 在 `WORDS_TO_FIX` 字典中設定你要修改的單字，格式為 `"原本的漢字檔名": "正確的假名發音"`。
       *(例如：`{"否": "いや", "明日": "あした"}`)*
    3. 儲存後執行：
       ```bash
       python 單一音檔修正.py
       ```

## 🛠️ AI 批改模式設定 (修改題數)

目前 AI 批改模式預設為 **5 題快速測試版**。若要切換回正式的 **25 題版**：
1. 打開 `script.js`。
2. 搜尋 `batchQuestions = dueWords.slice(0, 5);` (約位於 `startQuiz()` 函數內)。
3. 將 `5` 改回 `25` 即可。
